# =====================================================================
# GhostType — starter training corpus (simple phrases + focus lines)
# ---------------------------------------------------------------------
# This file is a hand-curated seed dataset shipped with the repo. It
# sits next to (and is merged with) the Cornell Movie-Dialogs corpus
# during training. Purpose:
#   1. Cover common everyday phrases ("how are you", "thank you", etc.)
#      that the chat bar will see constantly.
#   2. Cover common "focus lines" — sentence starters people actually
#      type when drafting notes / messages ("let me think", "i need to",
#      "the next step is", etc.).
#   3. Cover Jana-style introductions and Indian-English patterns so
#      suggestions feel natural to the operator.
#
# Training merges this file + the Cornell corpus at the line level, so
# every line here is treated as one independent utterance.
# Format: one phrase per line. Lowercase, no trailing punctuation.
# =====================================================================
